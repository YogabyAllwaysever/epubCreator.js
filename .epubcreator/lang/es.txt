help_title = 📚 epubcreator — CLI para compilar directorio a EPUB  (v{version})
help_commands = 
  node epubcreator.js createdir           Crear estructura de directorios y descargar configuración de la herramienta
  node epubcreator.js convertch           Convertir .md → .xhtml (predeterminado, busca en Markdowns/)
  node epubcreator.js convertch xhtml2md  Convertir .xhtml → .md
  node epubcreator.js convertch docx2md   Convertir .docx → .md (dividir por ##)
  node epubcreator.js conv ...            Alias para convertch
  node epubcreator.js split <ruta>        Dividir archivo .md por título ##
  node epubcreator.js merge <ruta>        Fusionar archivos .md en uno (inverso de split)
  node epubcreator.js build               Construir EPUB desde el directorio actual
  node epubcreator.js debug               Observar cambios en Markdowns/, auto convertch + build
  node epubcreator.js import              Importar archivo .epub desde el directorio actual
  node epubcreator.js updatemodule        Descargar/actualizar node_modules desde el repositorio
  node epubcreator.js updatemodule --force Actualizar sin confirmación
  node epubcreator.js updateconfig        Descargar/actualizar .epubcreator desde el repositorio (rama config)
  node epubcreator.js settings            Configuración interactiva de la herramienta
  node epubcreator.js validate            Validar el EPUB más reciente con epubcheck
  node epubcreator.js --version           Mostrar versión
help_structure = 
Estructura de directorios:
  ./
  ├── config.txt          ← metadatos del libro (obligatorio)
  ├── ord.txt             ← lista de orden de capítulos (opcional)
  ├── Docs/               ← archivos .docx fuente (para docx2md)
  ├── Markdowns/          ← archivos .md fuente (para convertch)
  ├── node_modules/       ← dependencias (descargadas automáticamente mediante updatemodule)
  ├── .epubcreator/       ← configuración de la herramienta y archivos de idioma (descargados automáticamente mediante createdir/updateconfig)
  │   ├── settings.txt
  │   └── lang/
  │       ├── en.txt
  │       └── id.txt
  ├── EPUB/
  │   ├── images/
  │   │   └── cover.png   ← OBLIGATORIO
  │   ├── audiovideo/     ← opcional
  │   ├── bab1.xhtml      ← capítulos (cualquier nombre, en la raíz de EPUB/)
  │   └── ...
  └── builds/
      └── [nombre-carpeta].epub   ← resultado de la compilación
help_deps = 
Nota: asegúrate de tener instaladas las dependencias principales:
  npm install archiver@5.3.0 marked@4.0.0 turndown@7.2.4
Para la función DOCX:  npm install mammoth@1.6.0 (opcional)
Para la función de importación: npm install adm-zip@0.5.10 xml2js@0.5.0 (opcional)
Para la validación: instala epubcheck (https://github.com/w3c/epubcheck)
