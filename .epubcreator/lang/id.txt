help_commands = 
  node epubcreator.js createdir           Buat struktur direktori dan unduh konfigurasi alat
  node epubcreator.js convertch           Konversi .md → .xhtml (default, cari di Markdowns/)
  node epubcreator.js convertch xhtml2md  Konversi .xhtml → .md
  node epubcreator.js convertch docx2md   Konversi .docx → .md (pisah berdasarkan ##)
  node epubcreator.js conv ...            Alias untuk convertch
  node epubcreator.js split <path>        Pecah file .md berdasarkan heading ##
  node epubcreator.js merge <path>        Gabungkan file .md menjadi satu (kebalikan dari split)
  node epubcreator.js build               Bangun EPUB dari direktori saat ini
  node epubcreator.js debug               Pantau perubahan di Markdowns/, otomatis convertch + build
  node epubcreator.js import              Impor file .epub dari direktori saat ini
  node epubcreator.js updatemodule        Unduh/perbarui node_modules dari repositori
  node epubcreator.js updatemodule --force Perbarui tanpa konfirmasi
  node epubcreator.js updateconfig        Unduh/perbarui .epubcreator dari repositori (cabang config)
  node epubcreator.js settings            Pengaturan alat interaktif
  node epubcreator.js validate            Validasi EPUB terbaru dengan epubcheck
  node epubcreator.js --version           Tampilkan versi

Struktur direktori:
  ./
  ├── config.txt          ← metadata buku (wajib)
  ├── ord.txt             ← daftar urutan bab (opsional)
  ├── Docs/               ← file .docx sumber (untuk docx2md)
  ├── Markdowns/          ← file .md sumber (untuk convertch)
  ├── node_modules/       ← dependensi (diunduh otomatis via updatemodule)
  ├── .epubcreator/       ← pengaturan alat dan file bahasa (diunduh otomatis via createdir/updateconfig)
  │   ├── settings.txt
  │   └── lang/

  │       └── id.txt
  ├── EPUB/
  │   ├── images/
  │   │   └── cover.png   ← WAJIB
  │   ├── audiovideo/     ← opsional
  │   ├── bab1.xhtml      ← bab (nama apa saja, di root EPUB/)
  │   └── ...
  └── builds/
