help_title = 📚 epubcreator — ディレクトリを EPUB にコンパイルするための CLI  (v{version})
help_commands = 
  node epubcreator.js createdir           ディレクトリ構造を作成し、ツール設定をダウンロード
  node epubcreator.js convertch           .md → .xhtml に変換 (デフォルト、Markdowns/ を参照)
  node epubcreator.js convertch xhtml2md  .xhtml → .md に変換
  node epubcreator.js convertch docx2md   .docx → .md に変換 (## で分割)
  node epubcreator.js conv ...            convertch のエイリアス
  node epubcreator.js split <パス>        .md ファイルを見出し ## で分割
  node epubcreator.js merge <パス>        .md ファイルを1つにマージ (split の逆)
  node epubcreator.js build               カレントディレクトリから EPUB をビルド
  node epubcreator.js debug               Markdowns/ の変更を監視し、自動 convertch + build
  node epubcreator.js import              カレントディレクトリから .epub ファイルをインポート
  node epubcreator.js updatemodule        リポジトリから node_modules をダウンロード/更新
  node epubcreator.js updatemodule --force 確認なしで更新
  node epubcreator.js updateconfig        リポジトリ (config ブランチ) から .epubcreator をダウンロード/更新
  node epubcreator.js settings            対話型ツール設定
  node epubcreator.js validate            epubcheck で最新の EPUB を検証
  node epubcreator.js --version           バージョンを表示
help_structure = 
ディレクトリ構造:
  ./
  ├── config.txt          ← 書籍メタデータ (必須)
  ├── ord.txt             ← チャプター順序リスト (オプション)
  ├── Docs/               ← ソース .docx ファイル (docx2md 用)
  ├── Markdowns/          ← ソース .md ファイル (convertch 用)
  ├── node_modules/       ← 依存関係 (updatemodule で自動ダウンロード)
  ├── .epubcreator/       ← ツール設定と言語ファイル (createdir/updateconfig で自動ダウンロード)
  │   ├── settings.txt
  │   └── lang/
  │       ├── en.txt
  │       └── id.txt
  ├── EPUB/
  │   ├── images/
  │   │   └── cover.png   ← 必須
  │   ├── audiovideo/     ← オプション
  │   ├── bab1.xhtml      ← チャプター (任意の名前、EPUB/ ルート直下)
  │   └── ...
  └── builds/
      └── [フォルダ名].epub   ← ビルド結果

注意: 主要な依存関係がインストールされていることを確認してください:
  npm install archiver@5.3.0 marked@4.0.0 turndown@7.2.4
DOCX 機能の場合:  npm install mammoth@1.6.0 (オプション)
インポート機能の場合: npm install adm-zip@0.5.10 xml2js@0.5.0 (オプション)
検証の場合: epubcheck をインストール (https://github.com/w3c/epubcheck)
  または "node epubcreator.js updatemodule" を実行して自動ダウンロードすることもできます。
